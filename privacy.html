Privacy notice

This notice explains how the public gitback2life website uses analytics and how the owner-operated, single-user Gmail assistant is designed to handle Google user data. The project is pseudonymous and aims to avoid publishing private identity information.

Google Analytics

This website uses Google Analytics 4 (GA4), provided by Google, to understand how visitors use the site and improve its pages. The site sends standard analytics events such as page views and engagement. Depending on browser and service settings, analytics may process information such as page URLs, browser and device details, approximate location, and identifiers or cookies used for measurement.

Google processes data under its own terms and privacy practices. Read Google's Privacy Policy for more information. The site owner does not use GA4 to intentionally request sensitive personal information.

Personal Gmail assistant — current status

The hosted Gmail reader is paused while the owner addresses Google's data-use, allowed-use-case, and restricted-scope security requirements. This feature must not be re-enabled until the applicable requirements are addressed.

The intended feature is user-directed email question-answering and summarization: when the owner asks a question, the assistant searches recent Inbox messages and uses ChatGPT to analyze the relevant content. Google lists generative-AI summaries as an approved Gmail productivity use case, but the exact request-and-return architecture has not been approved by Google; because it retrieves message text on demand, its classification must not be assumed.

Google data accessed and why

When enabled, the reader uses the Gmail API with the read-only gmail.readonly scope. It retrieves up to five newest Inbox messages matching the user's request, including message metadata and text. It does not fetch attachments. Message text is intended to be used only to answer the owner's requested email question or provide the requested summary or analysis.

How data moves

  1. Gmail provides matching messages to a GitHub-hosted Actions runner. That runner processes plaintext message content transiently in memory before encrypting the response. The workflow is designed not to print message bodies, headers, search filters, or credentials to logs.
  2. The response is encrypted for a temporary session key and posted as ciphertext in a comment on this public GitHub repository. The comment is public encrypted data and may persist on GitHub. It is not plaintext email, but it should not be assumed harmless if a private key is compromised.
  3. The encrypted response is decrypted in the active assistant session so ChatGPT can answer the owner's request. The selected message content is transferred to and processed by OpenAI's service under the applicable OpenAI terms, service controls, and account settings. This project does not control OpenAI's service retention systems.

The reader is designed not to change the Gmail mailbox. It does not intentionally sell email data, use it for advertising, or create a permanent email archive. GitHub comments and logs, and ChatGPT conversation handling, remain subject to the respective providers' controls and retention practices.

Disclosure and consent

Before each retrieval, the assistant must display an in-context disclosure of the message data accessed, GitHub-hosted plaintext processing, the public ciphertext comment, and the transfer to ChatGPT. It must obtain an explicit affirmative response for that particular request before it sends the request to the hosted reader. Silence or ambiguity is not consent.

Google Limited Use commitment

The use of information received from Google Workspace scopes will adhere to the Google Workspace User Data and Developer Policy, including the Limited Use requirements. The application will not intentionally use Google user data to train or improve general-purpose AI models or to create a permanent email dataset. Before the reader is re-enabled, the owner must verify that the selected ChatGPT service and account settings satisfy Google's restrictions; the application cannot guarantee provider-side retention or processing beyond the providers' published terms and controls.

Managing or deleting data

The owner can stop new access by keeping the hosted reader's compliance-ready gate disabled, delete request/response comments from GitHub, delete the relevant ChatGPT conversation using ChatGPT's controls, revoke the app's Gmail access in the Google Account's third-party connections, and remove the associated OAuth refresh token and GitHub secrets. Deletion in one service does not automatically delete data held by another service or immediately remove all provider backups or logs.

This is a single-user personal tool; there are no other enrolled users or public accounts. Do not put plaintext email, private sender filters, OAuth tokens, or private keys in public GitHub comments or commits.

Your choices

You can limit or prevent analytics collection using browser privacy settings and available controls. Google provides a Google Analytics opt-out browser add-on for supported browsers. Blocking scripts or cookies may affect measurement.

Contact and changes

This notice may be updated if the site's tools or data practices change. Do not submit sensitive personal, financial, medical, or account information through this public project website.
