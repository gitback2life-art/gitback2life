# Contributing

gitback2life is primarily a personal project, but constructive technical feedback and useful ideas are welcome.

## Good contributions

- bug reports with reproducible details
- suggestions for improving documentation
- practical accessibility improvements
- code-quality suggestions
- useful project ideas
- corrections to factual errors

## AI-assisted contributions

AI-assisted work is acceptable when the contributor reviews it, understands the change they are proposing, and takes responsibility for its accuracy and licensing.

Do not submit:
- copied material presented as original
- secrets or private information
- malicious code
- deceptive content
- automated spam

The project's goal is useful, honest progress.
