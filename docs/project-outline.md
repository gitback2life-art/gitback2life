# gitback2life — Project Outline

## Mission
Use AI, learning, and software building as practical tools for rebuilding life and moving toward independence.

## Pillars
- Rebuild: routines, organization, problem-solving, momentum
- Learn: programming, AI, technology, research, communication
- Build: useful software and experiments
- Independence: legitimate opportunities and sustainable self-support

## First milestone
Fund one month of continued ChatGPT access through a legitimate direct support method where eligible.

## Operating rules
- truthful
- pseudonymous
- no fake testimonials or engagement
- no impersonation
- no pressure tactics
- $0-upfront-cost-first
- no pay-to-unlock earnings
- protect passwords and private information
- verify platform rules before posting
- keep important decisions under the user's control

## Success
The project succeeds when the user increasingly handles life independently and no longer needs outside support for the tools used to rebuild.
