# gitback2life — Free Account Setup Plan

## Identity rules
- Use gitback2life wherever available.
- Use the dedicated project email.
- Use a unique password per service.
- Enable two-factor authentication when available.
- Do not use a personal profile photo unless it has been reviewed for identifying details.

## Recommended order
1. GitHub — source code and project history.
2. GitHub Pages — project site, using the GitHub repository.
3. One documentation or social platform — only after checking current rules.
4. One support community — only after confirming eligibility and request rules.

## Account purpose rule
Every account must have a documented purpose. Avoid opening accounts just to create the appearance of activity.
