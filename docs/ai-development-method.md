# AI-Assisted Development Method

gitback2life uses AI as a development partner, not as a substitute for judgment.

## Workflow

1. Define the problem.
2. Ask AI for multiple approaches.
3. Choose an approach.
4. Have AI help implement a small step.
5. Test the result.
6. Inspect failures and explain them.
7. Iterate.
8. Document what was learned.
9. Keep only changes that can be understood and verified.
10. Record the result in the build journal.

## Principles

- verify generated code
- do not commit secrets
- do not blindly paste code that is not understood
- document important architectural decisions
- prefer small, reversible changes
- keep a clear record of what AI contributed
- take responsibility for the final result
