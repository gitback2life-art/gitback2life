# gitback2life — Privacy Rules

## Public identity
Use only the project identity gitback2life and the dedicated project email for public-facing activity.

## Never publish
- legal name
- home address
- personal phone number
- personal email address
- medical records or disability documents
- government identification
- bank/card/account numbers
- passwords or recovery codes
- API keys or access tokens
- private gift-card PINs or claim links
- identifying photographs unless deliberately reviewed for privacy

## Important distinction
Anonymity is achieved by withholding identifying information, not by inventing false facts. If a platform, employer, payment provider, or government service legally requires identity verification, provide accurate information privately through that service.
