# gitback2life Brand Guide

## Core visual idea

The identity is a cyber-tech story about forward motion, practical resilience, and possibility.

The recurring visual language combines:
- Sunrise — a new beginning
- Mountains — the climb ahead
- Backpack — bringing experience into the next chapter
- Code — a practical tool for creating something useful
- Road / arrow — movement toward independence
- Neon glow — energy, technology, and possibility

## Primary palette

- Midnight: #030712
- Deep blue: #08111f
- Electric cyan: #00d9ff
- Neon violet: #8f5cff
- Sunrise gold: #ffb21c
- Growth green: #20e58a
- Warm white: #f3f8ff

## Voice

Confident but grounded. Hopeful without being sentimental. Technical without being cold.

Prefer:
- rebuild
- learn
- build
- move forward
- one step at a time
- real projects
- real progress

Avoid:
- exaggerated success claims
- pity-based messaging
- defining the person primarily by disability or recovery
- fake urgency
- overnight-success language
- corporate-sounding slogans

## Signature line

**Building what comes next, one line of code at a time.**

## Four recurring words

**REBUILD - LEARN - BUILD - INDEPENDENCE**

Use these consistently across profiles, website sections, project graphics, and progress updates.

## Avatar / logo guidance

Use the cyber-tech mountain/sunrise concept as the primary visual. For tiny avatar sizes, simplify to the mountain + sunrise + code mark and keep the silhouette/background high contrast.

## Account consistency

Where a platform permits it:
- username: gitback2life
- display name: gitback2life
- same profile artwork
- same signature line
- same short project description

The public identity remains pseudonymous. Never add private personal information to profile bios.
