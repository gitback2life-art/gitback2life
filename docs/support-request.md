# gitback2life — First Support Request Draft

## Title
Help provide one month of ChatGPT access while I rebuild

## Draft

I've been disabled for about 14 years and I'm working to rebuild my life and move toward greater independence.

One of the practical tools I'm using is ChatGPT. I'm using AI to learn, research, plan, solve problems, and build software. I've already created projects with AI assistance, including a task-management system, and I'm continuing to learn and build.

I'm keeping my real-world identity private for personal privacy and safety, but the story behind this project is truthful. I'm not claiming to be a charity, and I'm not promising a financial return to anyone.

My first goal is deliberately small: one month of continued ChatGPT access.

Where supported and eligible, I'd prefer direct assistance through an official OpenAI gift card or another official ChatGPT support mechanism rather than receiving cash. That keeps the assistance connected directly to the tool I'm using.

The long-term goal is not permanent dependence on donations. It's to use this period of support to learn, build useful software, find legitimate opportunities, and become increasingly independent.

Thank you for reading. Any support is voluntary, and no support is required to follow the project or wish me well.
