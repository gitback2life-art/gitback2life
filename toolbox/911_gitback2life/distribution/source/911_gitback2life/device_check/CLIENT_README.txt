911 GitBack2Life - Client Windows Computer Security Check

This folder is for the nonprofit / client who is requesting help.
1. Read this note and use only if you own/administer the Windows computer or have permission.
2. Double-click CLIENT_DEVICE_CHECK.cmd. Read the consent message and type YES only if you agree.
3. The collector saves one GB2L_CLIENT_DEVICE_REPORT_...zip into your Windows Downloads folder.
4. You can inspect the ZIP first. Send only the ZIP to your trusted volunteer.

It collects ONLY seven Windows-security status results: antivirus, signature freshness,
firewall, system drive encryption, inactivity lock policy, manual screen-lock reminder,
and Windows update/OS-support reminder. Some findings may be NOT VERIFIED.

It does NOT collect documents, browsing history, passwords, device identity, installed
program lists, network addresses, BitLocker recovery keys, or private case contents.
It does NOT connect back, control the computer, install or change any settings.
The volunteer cannot remotely access your computer by receiving this ZIP.
