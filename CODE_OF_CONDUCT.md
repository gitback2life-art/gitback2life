# Code of Conduct

gitback2life is intended to be a constructive project space.

We welcome:
- respectful discussion
- useful technical feedback
- honest questions
- constructive criticism
- sharing relevant knowledge

We do not welcome:
- harassment
- threats
- hate or personal attacks
- doxxing or attempts to identify the person behind the project
- scams or unsolicited money-making schemes
- requests for passwords, account access, or private information

Participation should help keep the project useful, safe, and focused on rebuilding, learning, building, and independence.
